# GitHub Pages Static Website

A beginner-friendly, responsive static website for Task 5.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — small JavaScript interaction

## Deploy with GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After deployment finishes, visit `https://YOURUSERNAME.github.io/`.

Make sure `index.html` remains in the root folder.
